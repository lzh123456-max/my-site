Small Hours Reading

A four-page reading companion for students. Build the bookshelf first: a good set of readable book entries and a useful filter will make the smallest version worth showing.

  • 01 / HomeThe idea, a featured book and a way into the collection.
  • 02 / BookshelfBook cards filtered by genre and reading length.

From thought to browser

How I would build it.

A little progress, tested and committed at each step.

  1. Choose the audience and write the first six book entries in my own words.
  2. Sketch the four pages and make a simple, consistent visual identity.
  3. Write semantic HTML, starting with the bookshelf and shared navigation.
  4. Add a responsive grid, then a labelled genre filter with JavaScript.
  5. Test links, images, keyboard controls and a narrow phone screen.
  6. Commit genuine changes as I work, publish the site, and collect screenshots.
