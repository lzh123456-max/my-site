A place to practise the small things that make a website work — and understand why they work.

A notebook, in website form.

Learning HTML is a learning project for the Web Technologies course. It brings together a home page, a literary quote collection, five project ideas and a playful machine. Each page is an opportunity to turn one lesson into something you can actually use.

The aim is to make the structure readable before adding decoration. The pages use meaningful elements, ordinary links and small scripts. There is no framework to hide how the pieces fit together.

A few deliberate decisions.

A warm paper background and book-like headings make the site feel like a notebook. Blue marks the places you can act. The same navigation and footer are loaded from shared files, so changing a link means editing one place.

The layout rearranges on a phone instead of shrinking a desktop page. Controls have visible labels and keyboard focus. The machine also respects a preference for reduced movement.

How AI helped with this project

AI assisted with the initial code, wording, illustration and review. The scripts are kept small and commented so their behaviour can be read, tested and explained. The literary quotations are linked to their original sources.

Lesson 2, put into practice

Meaning before appearance.

The element you choose should describe what the content is doing.

HTML choices used in this notebook
ElementWhat it meansWhere to see it
<nav>A group of navigation links.The shared menu at the top.
<blockquote>A quotation from another work.The sourced literary collection.
<dl>A set of terms and descriptions.Project ideas paired with audiences.
<button>An action, usable with a keyboard.The printer and the tag game.
<label>A visible name for a form control.Quote filters and the learning note below.
